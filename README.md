# Mi calabaza 🎃

Juego de español para decorar una calabaza, practicar vocabulario y describirla.

## Publicar con GitHub Pages
1. Descomprime este ZIP.
2. Sube index.html y .nojekyll a la raíz de tu repositorio (no subas solo el ZIP).
3. En Settings → Pages, selecciona Deploy from a branch.
4. Elige la rama main y la carpeta / (root), y guarda.
5. Abre la dirección que te muestre GitHub Pages cuando termine la publicación.

También puedes abrir index.html directamente en un navegador.

Incluye fondos de Halloween, piezas móviles, deshacer, ayuda en inglés opcional, modo A0 y avanzado, guardado del dibujo y controles de sonido y voz.
Las voces disponibles dependen del navegador y del dispositivo. Algunas voces necesitan conexión a internet. Las preferencias y el dibujo se guardan en el navegador utilizado.
